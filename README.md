# Радио Кострома ФМ — веб-плеер v2

Плеер прямого эфира с CORS-безопасным воспроизведением.

## Что чинилось в v2

Ошибка v1:

```

Политика одного источника запрещает чтение удалённого ресурса на
https://s0.radioheart.ru:8000/RH85296?t=... — отсутствует Access-Control-Allow-Origin. 403

```

Причина — две вещи разом:

1. `crossOrigin = 'anonymous'` на `<audio>` заставляет браузер делать CORS-запрос.
   Сервер RadioHeart не отдаёт заголовок `Access-Control-Allow-Origin` → 403.
2. `?t=` cache-buster в URL — некоторые Icecast-сервера отдают 403 на незнакомые query-параметры.

Обычный `<audio src="https://другой-домен/stream">` **не требует CORS** и играет всегда.
CORS нужен только когда мы хотим прочитать аудио-данные в Web Audio API (реальный спектр).

## Как это решено

- Поток грузится **без** `crossOrigin` по умолчанию → воспроизведение работает из любого origin.
- Перед первым play выполняется одноразовая CORS-проба через `fetch(..., {mode:'cors'})`.
  - Сервер отдал ACAO → включается **реальный** визуализатор (Web Audio AnalyserNode).
  - Сервер не отдал ACAO → включается **декоративный** визуализатор: рисует живую пульсацию
    без чтения аудио, реагирует на play/pause и синтезирует «бит». Выглядит живо, ничего не ломает.
- `?t=` убран — чтобы не провоцировать 403.

## Настоящий визуализатор без CORS (опция)

Если хочется реальный спектр, а прямого CORS нет — можно завернуть поток через прокси.
В `script.js`:

```js
const CORS_PROXY = 'https://corsproxy.io/?url=';
```

или любой другой префикс, к которому клеится `encodeURIComponent(url)`:

- `https://corsproxy.io/?url=`
- `https://api.allorigins.win/raw?url=`

После этого приложение проксирует поток, `crossOrigin` начинает работать, визуализатор — реальный.

**Торговля:** публичные прокси нестабильны, ограничены по трафику и видят весь аудиопоток.
Для себя надёжнее поднять свой: Cloudflare Worker в 20 строк, nginx с `add_header Access-Control-Allow-Origin *;`
и `proxy_pass` на `https://s0.radioheart.ru:8000/RH85296`.

## Запуск

Не открывай через `file://` — Web Audio и часть API блокируются. Нужен http-сервер:

```
python3 -m http.server 8080
# http://localhost:8080
```

## Деплой

Три файла (`index.html`, `style.css`, `script.js`) на любой статик-хостинг:
GitHub Pages, Netlify, Vercel, Cloudflare Pages. Сборка не нужна.

## Горячие клавиши

- `Space` — play / pause
- `↑` / `↓` — громкость
- `M` — мьют
